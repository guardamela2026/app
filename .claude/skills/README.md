# Skills del proyecto

Skills de Claude Code disponibles para quien trabaje en Guárdamela. Cada
carpeta con un `SKILL.md` es un skill; Claude Code los detecta solo al abrir
el proyecto.

## Instalados

De [emilkowalski/skills](https://github.com/emilkowalski/skills) — diseño y
animación de interfaces:

| Skill | Para qué |
|---|---|
| `emil-design-eng` | Prácticas de design engineering (paraguas general de UI). |
| `find-animation-opportunities` | Detectar dónde una micro-animación mejora la experiencia. |
| `improve-animations` | Auditar el movimiento del código y planificar mejoras. |
| `review-animations` | Revisar la animación de un cambio puntual. |
| `animation-vocabulary` | Terminología y conceptos base de animación. |

Se dejaron afuera `pick-ui-library` y `apple-design`: Guárdamela ya tiene su
sistema visual propio (neo-brutalista editorial) y no usa una librería de UI.
